# Kafka — Kafka Connect

Além dos servidores que formam a storage layer ([[kafka-cluster-e-brokers|brokers]]), outros servidores executam o **Kafka Connect** para constantemente importar e exportar dados como eventos na fila, integrando o Kafka com os sistemas existentes.
