# Kafka — Visão Geral

**Apache Kafka** é um sistema distribuído que consiste em [[kafka-cluster-e-brokers|Servers]] e [[kafka-clients|Clients]], que se comunicam a partir de um protocólo TCP de alta performance.

Kafka é uma plataforma de event streaming que é uma forma de integração por **Mensageria** ([[integracao-sistemas-mensageria]]). Por isso, muitos conceitos de mensageria são base para o funcionamento do Kafka, como, por exemplo, [[integracao-sistemas-event]], [[integracao-sistemas-producer]], [[integracao-sistemas-consumer]] e etc.
