# Integração de Sistemas — AMQP

AMQP (*Advanced Message Queuing Protocol*) é um protocolo específico para comunicação baseada em mensagens, utilizado por um [[integracao-sistemas-producer|Producer]] para enviar uma mensagem a um [[integracao-sistemas-message-broker|Message Broker]].
