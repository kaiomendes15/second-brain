# Integração de Sistemas — Event

Um evento é a mensagem em si. Pode ser um JSON, XML ou qualquer tipo de formato em bytes, enviado por um [[integracao-sistemas-producer|producer]] para uma [[integracao-sistemas-message-queue|queue]] de um [[integracao-sistemas-message-broker|Message Broker]].
