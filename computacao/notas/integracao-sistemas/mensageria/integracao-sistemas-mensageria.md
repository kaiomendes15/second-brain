# Integração de Sistemas — Mensageria

Mensageria é uma forma de comunicação entre sistemas em que aplicativos trocam dados de maneira assíncrona e indireta, utilizando um intermediário chamado **[[integracao-sistemas-message-broker|message broker]]**.

> **Em resumo:** *É o conceito que define que sistemas distribuídos possam se comunicar por meio de troca de mensagens (eventos), sendo estes eventos "gerenciados" por um Message Broker.*
