# Integração de Sistemas — Producer

É a aplicação que envia uma mensagem ([[integracao-sistemas-event|Event]]) para uma [[integracao-sistemas-message-queue|queue]] do [[integracao-sistemas-message-broker|Message Broker]]. No papel de "Sender", envia a mensagem sem saber onde os [[integracao-sistemas-consumer|Receivers]] estão, se estão ativos, ou quantos há.
