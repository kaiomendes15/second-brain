# TypeScript — Enums

Enums são uma feature que o TypeScript adiciona ao JavaScript para descrever um valor que pode ser um de um conjunto de constantes nomeadas.

Diferente da maioria das features do TypeScript, enums **não são apenas uma adição em nível de tipos** — eles existem em runtime. Por isso, é uma feature para usar com cautela: conheça a existência, mas avalie bem antes de adotar.

> Para detalhes completos, consulte a [Enum reference page](https://www.typescriptlang.org/docs/handbook/enums.html).
