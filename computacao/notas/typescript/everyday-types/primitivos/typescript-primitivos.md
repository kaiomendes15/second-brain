# TypeScript — Primitivos: string, number e boolean

JavaScript tem três primitivos amplamente usados: `string`, `number` e `boolean`. O TypeScript tem tipos correspondentes com os mesmos nomes — os mesmos que o operador `typeof` do JavaScript retornaria.

- `string` representa valores de texto como `"Hello, world"`
- `number` representa números como `42`. JavaScript não tem tipos distintos para inteiros e decimais — tudo é `number`
- `boolean` representa os dois valores `true` e `false`

> Os nomes com inicial maiúscula — `String`, `Number`, `Boolean` — são válidos mas se referem a tipos built-in especiais que raramente aparecem no código. Use sempre as versões em minúsculo.
