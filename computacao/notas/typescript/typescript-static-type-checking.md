### Static type-checking
Ferramenta do Typescript que permite identificar erros na forma de variáveis ou funções antes do código rodar. *Static type system* descreve as formas e os comportamentos que o valor vai ser quando o programa for executado. Typescript utiliza essa informação para dizer ao programador quando um trecho de código pode apresentar erro, antes da execução.
