# TypeScript — Intrinsic String Manipulation Types

Para ajudar na manipulação de strings ao redor de template string literals, o TypeScript inclui um conjunto de tipos que podem ser usados para manipulação de string dentro do sistema de tipos: `Uppercase<StringType>`, `Lowercase<StringType>`, `Capitalize<StringType>` e `Uncapitalize<StringType>`.

A documentação detalhada desses tipos vive na página de Template Literal Types do Handbook.
